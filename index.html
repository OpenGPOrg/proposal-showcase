Cards & Callouts

Responsive grid cards and highlighted problem-statement callout.

01 · Compute

Active Compute Network

Volunteer GPUs execute sequential pipeline stages and stream activations to adjacent peers.

02 · Resilience

Passive Storage Swarm

Non-GPU peers store Reed-Solomon erasure-coded activation shards indexed via Kademlia DHT.

03 · Memory

KV Cache Streaming

Full KV cache resides in CPU RAM; fast GPU summary filtering streams only top 5–10% to VRAM.

Problem Statement

How to enable organizations to run LLM inference across volunteers' personal devices without crashing from limited memory or losing progress when volunteers unexpectedly disconnect?
